## 1. What is HTML and what is its main responsibility in a web page?

中文：
 HTML 是 HyperText Markup Language，用来描述网页的结构。
 它的主要责任是告诉浏览器页面里有哪些内容，比如标题、段落、图片、按钮和链接。
 简单说，HTML 负责网页的“骨架”，不是负责样式或交互逻辑。

English:
 HTML stands for HyperText Markup Language.
 Its main job is to define the structure of a web page, like headings, paragraphs, images, buttons, and links.
 Basically, HTML is the skeleton of the page, not the styling or behavior.

------

## 2. What is an HTML file essentially made of?

中文：
 HTML 文件本质上是由很多 HTML elements 组成的。
 每个 element 通常由 opening tag、content 和 closing tag 组成。
 这些 elements 会按层级嵌套，形成整个页面结构。

English:
 An HTML file is basically made of HTML elements.
 Each element usually has an opening tag, some content, and a closing tag.
 These elements are nested together to build the full page structure.

------

## 3. What does `<!DOCTYPE html>` do and why is it required?

中文：
 `<!DOCTYPE html>` 告诉浏览器这个文件使用的是 HTML5 标准。
 它不是普通的 HTML tag，而是一个声明。
 它很重要，因为它可以让浏览器用标准模式解析页面，避免一些奇怪的兼容性问题。

English:
 `<!DOCTYPE html>` tells the browser that the page uses HTML5.
 It is not a normal HTML tag; it is a declaration.
 It is required because it helps the browser render the page in standards mode and avoids weird compatibility issues.

------

## 4. What is an HTML tag and how does it work?

中文：
 HTML tag 是用尖括号包起来的标记，比如 `<p>`、`<div>`、`<h1>`。
 它告诉浏览器某段内容的含义，比如这是段落、标题还是容器。
 大多数 tag 有开始标签和结束标签，中间放内容。

English:
 An HTML tag is a marker inside angle brackets, like `<p>`, `<div>`, or `<h1>`.
 It tells the browser what the content means, like a paragraph, heading, or container.
 Most tags have an opening tag and a closing tag, with content in between.

------

## 5. What is the difference between the `<head>` and `<body>` sections?

中文：
 `<head>` 里面放的是页面的元信息，比如 title、CSS link、meta tags。
 这些内容通常不会直接显示在网页主体里。
 `<body>` 里面放的是用户真正能看到和操作的内容。

English:
 The `<head>` section contains metadata, like the title, CSS links, and meta tags.
 Most things in the head are not directly shown on the page.
 The `<body>` section contains the actual content users can see and interact with.

------

## 6. What is an HTML attribute and why is it needed?

中文：
 HTML attribute 是写在 opening tag 里的额外信息。
 比如 `href` 告诉 `<a>` 链接要跳到哪里，`src` 告诉 `<img>` 图片地址在哪里。
 attribute 用来配置 element 的行为、样式或额外数据。

English:
 An HTML attribute is extra information inside the opening tag.
 For example, `href` tells an `<a>` tag where to go, and `src` tells an `<img>` tag where the image is.
 Attributes are used to configure an element’s behavior, style, or extra data.

------

## 7. How does the browser parse HTML and convert it into the DOM?

中文：
 浏览器会从上到下读取 HTML 文件。
 它会把 HTML tags 解析成一个树状结构，这个结构叫 DOM。
 JavaScript 可以通过 DOM 找到、修改或删除页面上的元素。

English:
 The browser reads the HTML file from top to bottom.
 It converts the HTML tags into a tree-like structure called the DOM.
 JavaScript can use the DOM to find, change, or remove elements on the page.

------

## 8. What is CSS and what problem does it solve?

中文：
 CSS 是 Cascading Style Sheets，用来控制网页的样式。
 它可以设置颜色、字体、间距、布局、动画等。
 它解决的问题是把页面结构和页面样式分开，让代码更清晰、更好维护。

English:
 CSS stands for Cascading Style Sheets.
 It is used to control the style of a web page, like colors, fonts, spacing, layout, and animations.
 It solves the problem of separating page structure from page styling, so the code is cleaner and easier to maintain.

------

## 9. Why is CSS not considered a programming language?

中文：
 CSS 不被认为是 programming language，因为它主要是声明样式，而不是写逻辑。
 它没有传统编程语言里的复杂控制流程，比如 loops、conditions 和 functions。
 CSS 更像是告诉浏览器“元素应该长什么样”。

English:
 CSS is not usually considered a programming language because it describes styles, not logic.
 It does not have normal programming features like loops, conditions, and functions in the same way JavaScript does.
 CSS is more like telling the browser how elements should look.

------

## 10. What are the three ways to apply CSS to an HTML page?

中文：
 第一种是 inline CSS，直接写在 element 的 `style` attribute 里。
 第二种是 internal CSS，写在 HTML 文件的 `<style>` 标签里。
 第三种是 external CSS，写在单独的 `.css` 文件里，再用 `<link>` 引入。

English:
 The first way is inline CSS, written directly in the `style` attribute.
 The second way is internal CSS, written inside a `<style>` tag in the HTML file.
 The third way is external CSS, written in a separate `.css` file and linked with a `<link>` tag.

------

## 11. Why are inline styles generally not recommended?

中文：
 Inline styles 不推荐，因为它会把 HTML 结构和 CSS 样式混在一起。
 这样代码会变得很难维护，也很难复用。
 在实际项目里，我们通常更喜欢用 class 和 external CSS 来管理样式。

English:
 Inline styles are not recommended because they mix HTML structure with CSS styling.
 This makes the code harder to maintain and harder to reuse.
 In real projects, we usually prefer using classes and external CSS files.

------

## 12. What is the difference between id selectors and class selectors in CSS?

中文：
 `id` selector 用 `#`，通常用来选中页面中唯一的元素。
 `class` selector 用 `.`，可以被多个元素重复使用。
 实际开发里，class 更常用，因为它更灵活、更适合复用样式。

English:
 An `id` selector uses `#`, and it usually targets one unique element on the page.
 A `class` selector uses `.`, and it can be reused by many elements.
 In real projects, classes are used more often because they are more flexible and reusable.

------

## 13. What is the difference between margin and padding?

中文：
 Margin 是元素外面的空间，用来控制元素和其他元素之间的距离。
 Padding 是元素里面的空间，用来控制内容和边框之间的距离。
 简单说，margin 是外边距，padding 是内边距。

English:
 Margin is the space outside an element.
 Padding is the space inside an element, between the content and the border.
 So basically, margin is outside spacing, and padding is inside spacing.

------

## 14. What is the difference between `position: relative` and `position: absolute`?

中文：
 `position: relative` 是相对于元素原本的位置进行移动。
 元素原本占的位置还会保留在页面布局中。
 `position: absolute` 会脱离普通文档流，并相对于最近的 positioned parent 定位。

English:
 `position: relative` moves an element relative to its original position.
 The element still keeps its original space in the layout.
 `position: absolute` removes the element from the normal flow and positions it relative to the nearest positioned parent.

------

## 15. What is JavaScript used for in a web application?

中文：
 JavaScript 用来给网页添加交互和动态行为。
 比如点击按钮、提交表单、更新页面内容、调用 API 都可以用 JavaScript 实现。
 HTML 负责结构，CSS 负责样式，JavaScript 负责行为。

English:
 JavaScript is used to add interaction and dynamic behavior to a web page.
 For example, it can handle button clicks, form submissions, page updates, and API calls.
 HTML is for structure, CSS is for styling, and JavaScript is for behavior.

------

## 16. What are the two ways to include JavaScript in an HTML file?

中文：
 第一种是 internal JavaScript，直接写在 HTML 文件的 `<script>` 标签里。
 第二种是 external JavaScript，写在单独的 `.js` 文件里，再用 `<script src="...">` 引入。
 实际项目里通常更推荐 external JavaScript，因为更清晰、更好维护。

English:
 The first way is internal JavaScript, written directly inside a `<script>` tag.
 The second way is external JavaScript, written in a separate `.js` file and included with `<script src="...">`.
 In real projects, external JavaScript is usually preferred because it is cleaner and easier to maintain.

------

## 17. What is a variable in JavaScript and what types of values can it store?

中文：
 Variable 是用来存储数据的名字。
 JavaScript 里的变量可以存数字、字符串、布尔值、数组、对象、函数等。
 常见的声明方式有 `let`、`const`，以前也会看到 `var`。

English:
 A variable is a name used to store data.
 In JavaScript, a variable can store numbers, strings, booleans, arrays, objects, functions, and more.
 Common ways to declare variables are `let` and `const`, and you may also see `var` in older code.

------

## 18. How does JavaScript interact with HTML elements through the DOM?

中文：
 JavaScript 可以通过 DOM 查找 HTML elements。
 比如可以用 `document.querySelector()` 选中一个按钮或输入框。
 选中之后，JavaScript 可以修改它的文本、样式、属性，也可以绑定事件。

English:
 JavaScript can use the DOM to find HTML elements.
 For example, it can use `document.querySelector()` to select a button or an input.
 After selecting it, JavaScript can change its text, style, attributes, or attach events to it.

------

## 19. What are loops used for in JavaScript, and can you give an example use case?

中文：
 Loops 用来重复执行一段代码。
 比如我们有一个商品数组，就可以用 loop 把每个商品渲染到页面上。
 常见的 loop 有 `for` loop、`while` loop 和数组方法比如 `forEach`。

English:
 Loops are used to repeat a block of code.
 For example, if we have a list of products, we can loop through the list and render each product on the page.
 Common loops include `for`, `while`, and array methods like `forEach`.

------

## 20. What is an event listener and why is it important in front-end development?

中文：
 Event listener 是用来监听用户行为或浏览器事件的机制。
 比如用户点击按钮、输入文字、提交表单时，JavaScript 可以执行对应的代码。
 它很重要，因为前端页面的大部分交互都依赖 event listener。

English:
 An event listener is a way to listen for user actions or browser events.
 For example, when a user clicks a button, types in an input, or submits a form, JavaScript can run some code.
 It is important because most front-end interactions depend on event listeners.
